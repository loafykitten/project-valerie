# Resources

Version small, reusable non-secret resources here when they exist: example workflows, neutral expression mappings, and prompt templates. Runtime prompt edits belong in SQLite, not in these files.

Put original character PNG/JSON, VRM models, animation licenses, and private ComfyUI workflows in `resources/private/` (ignored by Git). Preserve original bytes and attribution. Do not assume a VRM or animation is licensed for redistribution because this repository is private.

Character sources are imported privately with `bun character:import /path/card.png`. The repository ships without personal character prose. Original image/JSON and verification copies live beside the configured SQLite database, outside tracked resources.
